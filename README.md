## Compatibility

- A GPU and graphics driver with OpenGL 4.0 or newer support.
- [Iris](https://modrinth.com/mod/iris) 1.7.0 or newer.
- OptiFine is **not supported**.

### Mod Integrations

- [Voxy](https://modrinth.com/mod/voxy)
- [Distant Horizons](https://www.curseforge.com/minecraft/mc-mods/distant-horizons)
- [Physics Mod](https://www.patreon.com/Haubna)
- [Super Resolution](https://sr.187j3x1-114514.org/)
- [rrtt217's HDR Mod](https://modrinth.com/mod/rrtt217-s-hdr-mod)
